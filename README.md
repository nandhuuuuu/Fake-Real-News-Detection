
# Fake vs Real News Detection

## Project Overview
This project uses Machine Learning and NLP to classify news articles as Fake or Real.

## Dataset
Fake and Real News Dataset.

## Algorithms Used
- Logistic Regression
- Naive Bayes
- Random Forest

## Best Model
Random Forest

## Accuracy
99.81%

## Technologies Used
- Python
- Pandas
- NLTK
- Scikit-learn
- Streamlit

## How to Run

Install the required libraries:

pip install -r requirements.txt

Run the application:

streamlit run app.py
